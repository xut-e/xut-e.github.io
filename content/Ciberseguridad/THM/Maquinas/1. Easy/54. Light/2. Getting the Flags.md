![[Pasted image 20260825183720.png]]

Parece que nos da la contraseña del usuario, ahora vamos a tratar de conseguir el username del administrador.

![[Pasted image 20260825184440.png]]

Cuando ponemos un usuario inexistente, la aplicación nos devuelve `Username not found.`, esto significa que la aplicación está haciendo una query para mirar nombres de usuarios del estilo:

```sql
SELECT password FROM users WHERE username=input
```

Esto significa que puede que exista una vulnerabilidad de tipo SQLi. Para comprobarlo introducimos una `'`.
