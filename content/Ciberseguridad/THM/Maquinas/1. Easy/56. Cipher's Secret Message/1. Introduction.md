Uno de los mensajes secretos de Cipher fue recuperado de un sistema antiguo junto al algoritmo de encriptación, pero no somos capaces de descodificarlo.

- **Orden:** ¿Puedes ayudar a Void a descifrar el mensaje?
- **Mensaje:** `a_up4qr_kaiaf0_bujktaz_qm_su4ux_cpbq_ETZ_rhrudm`
- **Algoritmo de encriptación:** 

```python
from secret import FLAG

def enc(plaintext):
    return "".join(
        chr((ord(c) - (base := ord('A') if c.isupper() else ord('a')) + i) % 26 + base) 
        if c.isalpha() else c
        for i, c in enumerate(plaintext)
    )

with open("message.txt", "w") as f:
    f.write(enc(FLAG))
```
