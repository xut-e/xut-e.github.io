<h2>Escalada de Privilegios</h2>
Después de investigar las técnicas convencionales y no poder escalar nada, decidí listar servicios activos con `ss`:

![[Pasted image 20260909160010.png]]

Para escanear dichos puertos vamos a usar el comando:

```bash
for p in 3000 8080 8088 8089 9000 3306 4573 5038; do echo "==== $p ===="; curl -s -m 3 http://127.0.0.1:$p/ | head -c 200; echo; done
```
